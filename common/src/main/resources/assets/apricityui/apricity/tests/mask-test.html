Mask 测试

覆盖 mask-mode（alpha / luminance）、mask-composite（add / subtract / intersect / exclude）、 mask-clip / mask-origin 几何盒、url() 图像遮罩与失败 fail-open。每张卡片标注预期效果，与浏览器不一致即回归。

mode composite clip / origin url() / fail-open

mask-mode

alpha：黑→透明渐变
mask: linear-gradient(90deg, #000, transparent)
预期：内容自左向右淡出。
alpha：不透明彩色渐变（对照组）
mask: linear-gradient(90deg, red, blue)
预期：渐变 alpha 处处为 1，无任何遮罩效果。
luminance：白→红→黑
mask-mode: luminance
预期：按亮度遮罩——左侧几乎全显，红色段约 21% 可见，右侧全遮。与对照组（同渐变按 alpha 无效果）对比即 luminance 生效。
