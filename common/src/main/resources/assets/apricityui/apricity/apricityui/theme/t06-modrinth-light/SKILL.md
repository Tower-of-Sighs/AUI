# Modrinth Light — Design Skill

本文件是 `t06-modrinth-light` 的设计与代码生成规范。目标是在保留 Modrinth 视觉线索的同时，生成符合 ApricityUI 主题契约、具备完整交互状态的浅色界面。

## 何时使用

- 为 Modrinth 风格的项目浏览、内容目录、设置、仪表板和社区界面设计组件或页面。
- 为 ApricityUI 生成与 `t06-modrinth-light` 配合的标记和样式。
- 审核现有界面是否符合 Modrinth 的浅色表面、绿品牌色、紧凑圆角与清晰层级。

## 如何使用

- 将本文件规则作为设计约束，再补充具体产品、页面和内容需求。
- 输出前检查所有颜色是否用于正确的语义角色，所有交互是否提供状态和键盘反馈。
- ApricityUI 项目中优先使用主题已有的组件类，不复制或重写主题 CSS。

## 设计原则

- 以 Modrinth 的明亮、友好、内容优先的产品气质为基础：低对比表面层次、清晰深色文字、鲜明绿色品牌动作。
- 通过排版、留白和表面层级建立信息架构；避免依赖厚重描边、复杂装饰或大面积彩色背景。
- 组件造型参考 Modrinth UI 的圆角按钮、圆润输入框、胶囊开关和高密度内容列表，但必须遵守 AUI 的标记与状态契约。
- 品牌色用于关键操作和选择状态；语义色用于成功、警告、错误、信息，不把所有元素染成品牌绿。
- 视觉复刻不包含 Modrinth logo、品牌图案、站点插画或未经许可的品牌资产。

## 颜色与表面

| 角色 | Token / 色值 | 用途 |
| --- | --- | --- |
| 页面底层 | `--surface-1: #ebebeb` | 页面和大背景 |
| 次级底层 | `--surface-2: #f5f5f5` | 凹陷区域、输入内容底 |
| 卡片表面 | `--surface-3: #f8f8f8` | 卡片和主要容器 |
| 高亮表面 | `--surface-4: #ffffff` | 控件、浮层和抬高表面 |
| 分隔线 | `--surface-5: #dddddd` | 描边、分隔和轨道 |
| 主文字 | `--ink: #2c2e31` | 正文 |
| 标题文字 | `--heading: #1a202c` | 标题、重要标签 |
| 次级文字 | `--ink-muted: #484d54` | 辅助信息 |
| 品牌绿 | `--brand: #00af5c` | 主操作和品牌状态 |
| 品牌操作文字 | `--accent-text: #002b17` | 品牌填充按钮上的文字 |
| 错误 | `--red: #cb2245` | 危险操作和错误 |
| 信息 | `--blue: #1f68c0` | 链接与信息状态 |
| 辅助强调 | `--purple: #8e32f3`，`--warning-text: #a44419` | 促销/稀有度、警告 |

语义底色使用柔和的 `--success-soft`、`--warning-soft`、`--danger-soft`、`--info-soft` 和 `--purple-soft`。避免在淡色背景上直接使用对比度不足的浅色文字。品牌绿按钮的文字使用深色 `--accent-text`，而不是白色。

## 排版与布局

- 正文字体使用 Inter 风格系统无衬线栈；代码、标识符和快捷键使用 `--font-mono`。
- 正文默认约 16px；辅助信息约 14px；标题采用较重字重和紧凑字距，逐级递减。
- 常见间距以 4/8/16/24/32px 为阶梯。卡片内使用 16px 起步的留白。
- 卡片用细边框、约 16px 圆角和轻微投影；不要把每个内容区域继续包进嵌套卡片。
- 桌面布局居中并控制内容最大宽度；窄屏转为单列。表格保留自身列宽语义，并由外层容器横向滚动。

## 组件规则

### 按钮

- 主操作使用品牌绿填充和深色文字；次级操作使用浅色表面和细微描边/内描边；tertiary 操作用透明表面。
- 中号按钮约 36px 高、12px 圆角，文字 16px / 600；小按钮约 28px 高、14px 字号。
- 危险操作采用红色语义色，不得伪装成普通品牌按钮。
- 悬停采用轻微亮度或表面变化；按下反馈可以轻微缩放，不能引起布局跳动。
- 加载态必须显示与按钮实际背景有对比的进度符号，并隐藏重复提交的视觉暗示。

### 卡片与面板

- 使用浅色卡片表面、轻描边、适度圆角和宽松内容区。
- 标题与正文用字号、字重和间距区分，不默认加厚色带。
- footer 用细分隔线；彩色强调边仅用于明确的语义或项目状态。

### 表单、复选框与开关

- 输入框约 36px 高、12px 圆角，使用明亮表面、细边框和清晰 placeholder。
- 校验错误必须同时有错误文字/图标或字段状态，不得仅依赖颜色。
- 复选框约 20px，6px 圆角；开关约 48×24px，滑块圆点约 16px。
- 保留原生选择控件的键盘与禁用行为，并使用主题品牌 `accent-color`。
- 开关开态使用品牌填充与深色圆钮；禁用时保留开/关位置，不得强制复位。

### 滑杆与进度

- 滑杆轨道约 6px 高、圆角胶囊；填充使用品牌色，滑块约 10×32px。
- 进度轨道和填充形状一致，数值通过标签或文字明确表达。
- 设置行内滑杆必须具有实际可用宽度；窄屏下允许标签和控件换行。

### 导航、列表与数据

- 导航默认安静、轻量；活动项用柔和品牌底色和足够对比度的文字。
- 列表项点击区域保持清晰，hover 和 active 不混为同一状态。
- 表格用真实表格结构，浅色表头、细横向分隔线和温和的行 hover；不得将数据行改成 flex/grid 假表格。

### 下拉、菜单与提示

- 下拉菜单和菜单使用高亮表面、细边框、圆角和轻浮层阴影；长菜单限制高度并滚动。
- 选中项显示可见标记；箭头需同步反映展开状态。
- Tooltip 默认隐藏，悬停与键盘聚焦可显示；四方向定位，内容宽度不能被短触发按钮压窄。

### 模态、抽屉与通知

- 遮罩必须是独立的真实元素；大容器延续页面表面语言。
- 抽屉和模态限制视口内尺寸，主体独立滚动；移动端减少外围留白。
- 通知采用语义色柔和底色、细边框和明确状态文字。

## 状态与可访问性

- 所有交互组件覆盖默认、悬停、按下、键盘焦点、禁用；适用时覆盖选中、展开、错误、成功和加载。
- 焦点环清楚可见，不裁切、不仅靠颜色变化，也不使用 `outline: none`。
- 禁用态在 hover/active 时保持视觉稳定；图标伪元素分别处理，勾线和箭头内部保持透明。
- 颜色不是唯一信息渠道；关键状态同时使用文字、图标或形状。
- 尊重 `prefers-reduced-motion`；动效短、克制，不改变文档布局。

## 禁止项

- 不得将深色主题规则直接套在浅色主题上，只做全局反相。
- 不得在 `t06` 中使用暗色页面底、发光霓虹或重装饰游戏 UI。
- 不得对正文使用对比不足的浅灰色，也不得把白色文字放在浅色品牌底上。
- 不得使用厚阴影、渐变或玻璃拟态作为默认组件造型。
- 不得用伪选择器取代必要的真实文字、遮罩或语义标记。
- 不得移除 ApricityUI 核心类、状态钩子或要求调用方增加额外子元素。

## ApricityUI 主题接口

沿用 `t06-modrinth-light` 根作用域及主题 CSS 已实现的核心类。页面通过 `--canvas`、`--surface`、`--ink`、`--brand` 等语义 token 组织内容；不把主题专用颜色硬编码到组件内。组件状态兼容 `.on` / `:checked` / `[aria-checked="true"]` / `[data-state="on"]`，活动类 `.active` / `[aria-selected="true"]`，展开类 `.open` / `.show` / `[data-state="open"]` / `[aria-expanded="true"]`，以及禁用类 `.disabled`、`[disabled]`、`[aria-disabled="true"]`。

## 生成后自检

1. 表面层次清晰，页面底色、卡片表面、输入表面没有混成一层。
2. 品牌绿只用于主操作与选择状态；危险、警告、信息各自采用语义色。
3. 窄屏 320px 无页面横向溢出；表格可在容器内横向滚动。
4. 键盘焦点可见，禁用态不响应 hover，开态禁用开关仍保持开态。
5. 所有按钮、输入、卡片、表格和浮层保留对应的 AUI 类契约。
6. 减少动态效果时，界面不依赖动画传达状态。
