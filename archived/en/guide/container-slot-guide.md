# ApricityUI `container` / `slot` / `recipe` Guide

Last updated: 2026-07-22

## 1. Overall Model

AUI uses one slot tag: `<slot>`.

- `SlotDataBinder` binds matching slots inside a container to real menu slots by index; runtime code can inspect this
  internal state through `Slot.isBound()`.
- Slots outside a `container`, slots that do not match a menu slot, and slots generated by `<recipe>` are display slots
  whose item source is parsed from `innerText`.
- `isBound()` is not a template-authored HTML attribute. It reflects a real menu binding only, so templates cannot spoof
  a bound slot.
- `container` uses `layout` only to describe slot arrangement; write titles as ordinary DOM nodes.
- `recipe` generates display slots and never creates a real menu binding.

## 2. `container` Attributes

### 2.1 `bind`

- Binds a data source such as `player`, `saved_data`, `block_entity`, or `entity`.

### 2.2 `layout`

- Slot layout rules, either grid-style or presets.
- Examples:
  - `layout="[27,3,9]"`
  - `layout="preset:player"`

`layout` affects arrangement only. In normal cases it does not create missing slot instances automatically.

### 2.3 Titles

`container` has no built-in title mechanism. It does not read a `title` attribute or infer a title from its first child.
Write and lay out titles as ordinary DOM nodes.

```html
<div class="demo-title">My Title</div>
<container primary="true" bind="player" layout="preset:player">
  <slot slot-index="0" repeat="36"></slot>
</container>
```

## 3. `slot` Attributes

### 3.1 `repeat`

- Batch generation with total-count semantics.
- `repeat="36"` means 36 slots total, counting the template node itself as index 0.

### 3.2 `slot-index`

- Local slot index.
- Inside a container, it selects the data-source position to bind.

### 3.3 `interactive`

`interactive` controls item tooltip and real menu-slot operations independently. It never controls item/background
visibility.

- `tooltip`: allows the current item tooltip.
- `slot`: allows pickup, placement, dragging, shift-click, hotkeys, and other vanilla menu-slot operations for a bound
  slot.
- `tooltip slot`: enables both capabilities.
- `none`: enables neither capability.
- Tokens may be separated by spaces or commas, for example `interactive="tooltip slot"`.
- Legacy boolean spellings remain compatible: `true` / `1` mean `tooltip slot`, while `false` / `0` mean `none`. New
  templates should use capability tokens.

When omitted:

- Bound slots default to `tooltip slot`.
- Display slots and recipe slots default to `tooltip`: they show item information but cannot move items.

`slot` no longer uses `disabled` as an item-interaction switch. Use `interactive="none"` when all slot capabilities must
be disabled.

### 3.4 Display Item Attributes

- `innerText`: item literal (the only supported entry)
  - Item id: `minecraft:diamond`
  - Tag: `#minecraft:planks`
  - Id plus NBT: `minecraft:diamond_sword{Damage:12}`
  - Full ItemStack NBT: `{id:"minecraft:diamond",Count:1b,tag:{display:{Name:'{"text":"Preview"}'}}}`
  - Pipe-separated candidates: `minecraft:iron_ingot|minecraft:gold_ingot|minecraft:copper_ingot`
  - JSON Ingredient array: `[{"item":"minecraft:oak_log"},{"item":"minecraft:birch_log"}]`
- `cycle-interval` (alias `rotate-interval`): candidate rotation interval in ms; default 1000, minimum 200.
- `cycle`: whether to enable rotation (`true` / `false`); default `true`.

### 3.5 Rendering Control

`render` controls visual layers only:

- `all` (default): background, item model, and decorations.
- `item`: item model, glint, count, durability, and cooldown decorations only.
- `bg`: background only.
- `none`: neither background nor item.
- Missing, empty, or invalid values are treated as `all`.

No `render` value changes `interactive` tooltip or menu-operation capabilities.

Standard Item / BlockItem models are submitted through AUI content nodes. Forge custom renderers (ISTER/BEWLR) are
delegated by `ItemDrawer` in the same GUI PoseStack, depth, and clipping context. Dynamic standard models use mesh
caching only for the current frame, avoiding stale quads across frames. A model-resolution or third-party-renderer
exception draws AUI's magenta-and-black checkerboard and never falls back to vanilla `GuiGraphics.renderItem`.

Forge `ItemDecorator` extensions still depend on vanilla `GuiGraphics` decoration rendering and are not invoked.
Tooltips themselves are still drawn by Minecraft.

### 3.6 Styling

- Items are auto-centered inside the slot; use container/recipe `gap` for spacing.
- CSS such as `position/top/left/...` may still be used for manual layout.

## 4. Player Container Default 36 Slots

When `container.bind="player"` has no slot children, AUI injects player inventory slots implicitly:

- `inv`: 27 slots (3×9).
- `hotbar`: 9 slots (1×9).
- Default gap: `4px`.

Explicit slot declarations disable this implicit injection.

## 5. `recipe` Rules

- `<recipe>` can be used independently in normal HTML display.
- Multiple `<recipe>` tags may exist inside a container, each with its own sub-layout.
- Recipe-generated slots default to `interactive="tooltip"`: item information is available, but they never bind to a
  real menu or move items.
- Syntax: `<recipe type="...">recipe_id</recipe>`.
- `type` is required and validated strictly. Recommended values:
  - `crafting_shaped`
  - `crafting_shapeless`
  - `smelting` / `blasting` / `smoking` / `campfire_cooking`
  - `stonecutting`
  - `smithing`

## 6. Examples And Entry Points

- `minecraft:diamond` -> `run/apricity/test/index.html`
- `minecraft:emerald` -> `run/apricity/test/saveddata_player.html`
- `minecraft:amethyst_shard` -> `run/apricity/test/virtual_container.html`
- `minecraft:nether_star` -> `run/apricity/test/recipe_showcase.html`

```html
<div class="demo-title">SavedData Storage (9 slots, primary)</div>
<container primary="true" bind="saved_data" layout="[9,3,3]">
  <slot repeat="9" slot-index="0"></slot>
</container>

<div class="demo-title">Player Inventory (36 slots)</div>
<container bind="player" layout="preset:player">
  <slot repeat="36" slot-index="0"></slot>
</container>

<slot interactive="tooltip">{id:"minecraft:diamond",Count:12b,tag:{display:{Name:'{"text":"Example Item"}'}}}</slot>
<recipe type="crafting_shaped">minecraft:crafting_table</recipe>
```
