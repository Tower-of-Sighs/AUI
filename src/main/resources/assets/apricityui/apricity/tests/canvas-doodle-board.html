Ready
Checks
1. 连续拖动时笔迹应连贯，鼠标位置与线条起点应贴合。
2. 橡皮擦应真正擦掉像素，而不是盖白色块。
3. Undo / Redo 应恢复画布快照。
4. Export 应返回 `data:image/png;base64,...`。
5. `event.buttons` 释放鼠标后应停止绘制。
