AUI Item Rendering Regression
验证标准 Item/BlockItem、Forge BEWLR、动态模型解析、Item interactive 能力、内容裁剪与 AUI fallback。
A. 普通 Item / 标准 3D BlockItem
minecraft:diamond minecraft:apple minecraft:crafting_table minecraft:glass
钻石、苹果、工作台、玻璃应由 AUI 标准 quad 路径显示。
B. Forge ISTER / BEWLR
minecraft:shield minecraft:trident minecraft:chest
盾牌、三叉戟和箱子不应再稳定落入紫黑棋盘格；自定义 renderer 应在 AUI 内容盒中提交。
C. 动态标准模型 / override
minecraft:clock minecraft:compass minecraft:recovery_compass
进入世界后改变时间或朝向，时钟和指南针应逐帧更新，不得复用上一帧的 mesh。
D. 背景与物品显示差异（CSS）
minecraft:emerald minecraft:gold_ingot minecraft:redstone minecraft:lapis_lazuli
第二格只留 Slot 背景；第三格通过 CSS 只留 Item；第四格通过 CSS 隐藏背景和 Item。
E. 大槽位、数量、耐久、附魔和冷却
minecraft:diamond_sword minecraft:enchanted_book minecraft:ender_pearl
通过容器交互观察真实数量、耐久、附魔层与冷却遮罩。
F. opacity / filter / transform / overflow
minecraft:diamond_block minecraft:shield minecraft:trident
标准模型和 BEWLR 都应跟随元素 opacity、filter、transform 和父级 overflow 裁剪。
G. Item interactive=tooltip / slot / all / none
minecraft:netherite_ingot minecraft:iron_ingot minecraft:diamond minecraft:barrier
interactive 仅设置在 Item：tooltip 显示提示，slot 仅允许取放，all 同时启用两者，none 全部禁用。
H. WorldWindow、异常 fallback、鼠标携带 / quick craft
minecraft:oak_log minecraft:debug_stick
在 WorldWindow 中打开此页面；容器场景拖动或快速合成时，鼠标物品应由 AUI overlay 绘制。只有模型/BEWLR 实际抛错时才显示紫黑棋盘格。
