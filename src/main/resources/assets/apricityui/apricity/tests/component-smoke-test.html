AUI Component Smoke Test
用途: 回归常用组件的基础交互，重点覆盖 textarea 的 focus / 编辑 / 回车 / value 同步 / 滚动。
覆盖点
1. input / textarea 的 focus / blur
2. textarea 多行编辑与 Enter 插入换行
3. textarea 的运行时内容以 value 为准
4. select / option / checkbox / radio 状态更新
5. span / pre / img / sprite / translation / slot 显示
手动验证
1. 先点 textarea，确认右侧出现 focus 日志。
2. 在 textarea 里输入字符并按 Enter，再点 Read Value。
3. 内容超过盒子高度后，滚轮应能滚动 textarea。
4. 点 Set Demo / Clear，确认 textarea 内容和镜像同步变化。
5. 切换 checkbox / radio / select，确认日志和状态文本更新。
